# 💰 Convert Money

Um conversor de moedas desenvolvido com **HTML, CSS e JavaScript**, permitindo converter valores em **Real (BRL)** para **Dólar Americano (USD)**, **Euro (EUR)** e **Guarani Paraguaio (PYG)**.

O projeto foi desenvolvido com foco na prática de manipulação do DOM, eventos e formatação de moedas utilizando a API `Intl.NumberFormat`.

## 🚀 Funcionalidades

* ✅ Conversão de Real para Dólar Americano
* ✅ Conversão de Real para Euro
* ✅ Conversão de Real para Guarani Paraguaio
* ✅ Alteração dinâmica da bandeira da moeda selecionada
* ✅ Alteração automática do nome da moeda
* ✅ Formatação dos valores utilizando `Intl.NumberFormat`
* ✅ Interface simples, responsiva e intuitiva
